# 🛒 Instacart Grocery Analysis - Análise Exploratória de Dados

Projeto avançado desenvolvido no bootcamp da **TripleTen** focado na manipulação, limpeza e análise exploratória de bases de dados relacionais de uma plataforma de entrega de supermercado (*Instacart*).

## 🚀 Tecnologias Utilizadas
- **Python** (Pandas, Matplotlib)
- **Jupyter Notebook**
- **Análise de Dados Relacionais** (múltiplas tabelas)

## 🎯 Objetivos do Projeto
- **Visão Geral:** Analisar a estrutura de 5 datasets diferentes (pedidos, produtos, corredores, departamentos e itens de pedidos) para identificar inconsistências, dimensões e tipos de dados.
- **Pré-processamento e Limpeza:** Tratar valores ausentes críticos, detetar e remover pedidos ou produtos duplicados e corrigir tipos de dados.
- **Análise Exploratória (AED):** Responder a questões de negócio fundamentais sobre os hábitos de compra dos utilizadores (como os horários mais populares, dias da semana com maior movimento, frequência de recompra e produtos mais populares por corredor/departamento).

## 💡 Principais Aprendizagens
Consolidação de competências avançadas de junção (*merges*), agregações e limpeza de grandes volumes de dados do mundo real, essenciais para a tomada de decisão informada em equipas de dados.
